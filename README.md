
# Sistema de Gerenciamento de Restaurantes

Projeto desenvolvido em Python durante o curso de Python da Alura, com o objetivo de praticar conceitos fundamentais de lógica de programação e desenvolvimento de aplicações.
O Sistema de Gerenciamento de Restaurantes é uma aplicação executada via terminal que permite cadastrar restaurantes, visualizar os estabelecimentos cadastrados e alterar seus estados de ativação.

## como funciona?

- **Cadastrar restaurante:** permite adicionar um restaurante informando seu nome e categoria.
- **Listar restaurantes:** exibe os restaurantes cadastrados, suas categorias e seus respectivos status.
- **Ativar ou desativar restaurante:** permite alternar o status de ativação de um estabelecimento.
- **Validação de dados:** verifica campos vazios e evita o cadastro de restaurantes com nomes duplicados.
- **Tratamento de erros:** identifica entradas inválidas no menu.

## Tecnologias utilizadas

- Módulo `os`
